# Vinay Sharma: Personal Profile Site

Static portfolio site (HTML, CSS, JavaScript) published with GitHub Pages.

Live site: https://Vinay08sharma.github.io/

## Files

```
index.html
styles.css
script.js
```

## Preview locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

Or open `index.html` directly in a browser.

## Deploy

GitHub Pages serves the `main` branch from the repository root (Settings → Pages → Deploy from a branch → `main` / `/ (root)`).

## Custom domain (optional)

1. Add a `CNAME` file with your domain.
2. Point your DNS records at GitHub Pages.
3. Enable HTTPS in the Pages settings.
